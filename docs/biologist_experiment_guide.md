# 生物同学实验运行与填表指南

这份流程不要求理解神经网络代码。你的任务是：每次只运行一个版本，生成一份自动填好数值的报告，再用生物学语言补完“观察-解释-决策”。

## 0. 第一次准备

在仓库根目录打开 PowerShell：

```powershell
python -m pip install --no-deps --no-build-isolation -e ".[dev]"
pytest
```

看到 `passed` 即说明安装正常。`configs/baseline.yaml` 中是本地数据路径和训练设置；不要修改蛋白筛选阈值、随机种子或验证切分，除非本次实验的目的就是验证该项改动。

## 1. 每次实验的固定四步

以 v4 的 OOF 先验为例。将 `RUN_NAME` 换成一个从未使用过的名字，例如 `runs\my_oof_repeat`。

```powershell
# 1) 先检查输入文件和样本对齐
python -m goai_baseline.audit --config configs/baseline.yaml

# 2) 训练一个版本
python -m goai_baseline.train --config configs/baseline.yaml --variant p1_oof_priors --run-dir runs\my_oof_repeat

# 3) 按官方手册代理口径补充评分
python -m goai_baseline.score --config configs/baseline.yaml --run-dir runs\my_oof_repeat --output runs\my_oof_repeat\official_proxy_metrics.csv

# 4) 自动生成中文填写报告；第二个目录是比较对象，可按需要替换或删除
python scripts\build_experiment_report.py --run-dir runs\my_oof_repeat --compare-run runs\v4_p1_oof_rerun
```

完成后打开 `runs\my_oof_repeat\experiment_report.md`。它会自动展示本次的数值、与比较运行的变化以及读法；只需填写“生物学填写区”和最后的决策。

## 2. 怎样选运行命令

| 目的 | 训练命令中的 `--variant` | 用途 |
|---|---|---|
| 复现最小条件模型 | `p0_onehot` | 确认最基础的条件 MLP 是否可运行 |
| 复现原始文档统计先验 | `p1_priors` | 仅作为历史基准，不推荐作为新模型的训练参考 |
| 当前推荐的统计基准 | `p1_oof_priors` | 去除了训练行自身的统计先验信息 |
| 条件交叉 | `p2_crosses` | 单独测试显式条件组合是否有益 |
| 时间编码 | `p3_time` | 单独测试时间表示 |
| 名称散列 | `p4_hash` | 仅验证稳定数值编码，不能解释为化学结构信息 |

一次实验只改一个因素。若要改学习率或轮数，先复制配置文件，写清新文件名，并在报告的“唯一假设”中说明。

## 3. 看报告时先回答这三个问题

1. **这次想改善哪个场景？** 新化合物看 S1，新菌株看 S2，双重未知看 S3，时间问题看时间外推。
2. **绝对丰度和扰动变化是否同时改善？** `abs R2` 说明完整蛋白质组是否接近；`FC PCC` 说明处理相对对照的变化是否接近。两者都重要。
3. **相对于比较对象是否改善？** 不要只看一个看起来高的数字。自动报告会写出提高、降低或持平。

## 4. 一个填写示例

```text
最重要的现象：S3 的 FC PCC 没有提高。
可能的生物学解释：当前输入没有提供新化合物与已知化合物的结构相似性，因此模型可能无法迁移药物作用信息。
下一步决策：回退该改动；下一次只测试可核验的化合物结构表征。
```

这是“假设”，不是机制结论。只有得到外部证据或后续实验支持时，才能将其提升为生物学解释。

## 5. 架构的最简解释

- **输入**：菌株、化合物和培养条件，相当于描述“给哪种酵母在什么环境下施加什么处理”。
- **输出**：每个样本的完整 `log2` 蛋白丰度图谱。
- **MLP**：一个把多项条件组合成高维输出的函数；它不天然理解新菌株或新化合物的生物学相似性。
- **统计先验**：从训练数据中得到的平均背景或平均响应，帮助预测稳定部分；OOF 版本不允许一行样本借用自己的测量值。
- **匹配对照 FC**：处理样本减去相同实验上下文的对照，重点看“处理改变了什么”，而不是只看细胞原本长什么样。

## 6. 出现问题时

- `pytest` 失败：先不要运行训练，把完整错误记录在实验问题中。
- `official_proxy_metrics.csv` 不存在：先执行第 1 节第 3 步，再生成报告。
- FC 指标显示“不适用”：说明该场景无法形成足够的匹配对照或有效相关性；这是数据覆盖信息，不应自行填 0。
- 训练结果与上一次不同：确认配置、随机种子、分支和运行目录；再判断是否只是随机波动。
