# 虚拟细胞：当前问题、改进方向与参赛战略

> 状态：基于官方赛道手册、官方解题思路，以及本仓库已完成的基线复现实验整理。
> 本文区分已经验证的事实、需要验证的假设与尚未实现的方向。官方手册注明赛程和评测细则以组委会最新发布版本为准；任何实现前均应以最新规则复核。

## 1. 战略结论

本题不是普通的多输出回归，而是一个同时要求**绝对蛋白质组真实性**、**扰动响应（fold change, FC）**和**实体级分布外泛化**的问题。官方主榜将绝对保真度（20%）、匹配对照后的原始 FC（25%）、新化合物的上下文均值残差（20%）、新菌株的药物均值残差（20%）、双重未知/时间外推（10%）和高效应蛋白检出（5%）组合计分。

这直接决定了研发顺序：

1. 先让本地验证口径尽可能复现官方六模块，而不是依据单一 RMSE 或总 R2 选模型。
2. 把“背景丰度/观测过程”与“扰动响应”分开建模，优先学习与 FC 和残差指标直接相关的信号。
3. 对未见化合物和未见菌株，必须引入可迁移的实体表征；单纯的类别编码没有足够信息完成真正外推。
4. 每次只验证一个假设，并在 `S1`、`S2`、`S3` 和时间外推上分别报告结果。`S3` 是最严格的泛化场景，不能被大样本切分的均值掩盖。
5. 将可复现、可审计和科学解释作为与性能并列的交付物。赛事统一评审中，技术性能占 45%，科学意义 30%，方法创新性 20%，开源贡献 5%。

因此，近期最优路线不是立即堆叠大模型，而是先补齐“评分对齐 + 响应目标 + 无泄漏验证”这三个地基；随后按封闭数据与开放知识两条合规路线开展实体泛化。

## 2. 任务重新表述

给定菌株、化合物、培养基、温度、处理时间和可用测量上下文，输出完整的 `log2` 蛋白质组向量。难点来自三个层面：

- **高维且不完整的输出。** 原始蛋白空间有 5,243 个蛋白；当前训练集规则下保留 4,422 个训练缺失率严格低于 0.80 的蛋白。缺失表示未观测，不能当作零参与误差计算。
- **实体级 OOD。** `S1` 是已见菌株上的未见化合物，`S2` 是未见菌株上的已见化合物，`S3` 是两者同时未见。它们不是随机留出样本。
- **预测目标包含两类信号。** 绝对丰度受菌株、培养环境和测量过程影响；评测又显式要求处理相对于匹配对照的变化，以及去除共享效应后的特异响应。只学前者会得到看似平稳、却难以区分扰动的预测。

建议用下式作为后续模型设计的概念边界，而不是宣称已经完成的架构：

```text
预测蛋白质组 = 背景/对照状态(生物条件, 测量上下文)
             + 扰动响应(菌株表征, 化合物表征, 培养条件, 时间)
             + 可选的交互残差
```

这里“背景/对照状态”是可预测的模型分支，不是推理时读取某个实验样本。匹配对照仅用于从训练数据构造响应监督和本地诊断；提交预测必须仅依赖发布的元数据与允许的训练/外部资源。

## 3. 已完成的基线与可信结论

### 3.1 已完成的工程基线

当前仓库已完整复现官方解题思路中的基线阶梯：

- 以 `sample_ID` 显式对齐元数据与蛋白矩阵。
- 仅在训练行计算蛋白缺失率，保留阈值以下的蛋白；对正强度做 `log2`，并以观测 mask 计算 MSE。
- `B0`：逐蛋白训练均值。
- `B1`：在来源、仪器、板号、菌株、培养基、温度、时间及时间单位完全一致时的 Water/DMSO 匹配对照诊断。
- `P0`：菌株、化合物、培养基、温度、时间的类别编码，接两层 256 宽度的 MLP。
- `P1` 至 `P4`：依次加入训练统计先验、显式交叉、时间周期编码和确定性名称散列。

数据流、输出契约、提交格式校验、运行清单和单元测试已经落地。它们是后续实验的参照系，不应被提分模块直接改写。

### 3.2 当前结果说明了什么

当前冻结切分共有 8,958 行，训练行为 5,920 行；验证场景样本数分别为：

| 场景 | 样本数 | 基线读法 |
|---|---:|---|
| `val_chem_only` | 1,065 | 新化合物外推 |
| `val_strain_only` | 1,547 | 新菌株外推 |
| `val_both` | 269 | 双重未知外推 |
| `val_time` | 157 | 时间外推 |

`B0` 的 `log2 RMSE` 依次为 1.006、0.885、0.995、0.883。这是绝对丰度预测的必要下界，而不是响应预测的成功标准。

`B1` 在可精确匹配对照的局部子集上有明显更低的 RMSE：0.356、0.381、0.359、0.412；逐蛋白 R2 中位数为 0.857、0.755、0.835、0.751。它证明了背景、条件和观测上下文具有强解释力，也证明“只要接近对照”会是非常强的局部参照。`B1` 是诊断工具，不能替代无对照输入下的预测模型。

`P0` 的训练损失从 473.13 降到 2.93，但 OOD RMSE 为 3.115、3.390、6.352、1.121，明显差于 `B0` 和 `B1`。这不是训练流程失败，而是一个有价值的反证：对未见菌株或化合物，`P0` 的类别块退化为全零，且模型在直接拟合绝对丰度。`P1` 至 `P4` 相比 `P0` 明显改善，但仍未超过 `B1`；关键 OOD 场景的逐蛋白 R2 中位数仍为负，不能被解释为有效的生物响应预测器。

## 4. 目前的问题，按优先级排序

### P0. 本地选择指标没有完全对齐官方主榜

当前基线主要报告 `log2 RMSE`、全局 R2 与逐蛋白 R2。它们足以审计数据流，却无法回答模型是否学到 FC、化合物特异残差、菌株背景调制，或高效应蛋白方向。官方评分中，FC 与两类残差合计占 65%。

**风险：** 可能选出绝对丰度误差较低、但对扰动无辨识力的模型。

**第一项修复：** 实现本地官方风格评估器，所有参照统计、归一化与匹配规则仅从每个实验的训练部分冻结。输出必须按场景拆分，至少包含：

- 逐样本和逐蛋白的相关性/R2；
- 匹配对照的 FC Pearson 相关；
- 新化合物场景的上下文均值残差相关；
- 新菌株场景的药物均值残差相关；
- 双重未知和时间外推的绝对保真度与原始 FC；
- `|FC| > 1` 的方向准确率、高效应相关性及 precision-aware 的检出指标。

在实现前，需把官方匹配字段、可评分掩码、聚合方式和常数处理写成测试用例。若官方后续发布更精确的脚本或说明，应以其替换本地近似实现。

### P0. 当前目标把背景丰度与扰动响应混在一起

绝对 `log2` 丰度是稳定但很强的背景信号，导致均值或对照型预测在 RMSE 上具备优势；而比赛核心则强调 `treatment - matched_control` 的变化。当前端到端 MLP 没有显式区分这两类来源，也没有以 FC 作为监督目标。

**风险：** 模型向平均状态收缩，绝对值不差，但药物特异响应、上调/下调方向和高效应蛋白都被稀释。

**第一项修复：** 从训练数据中按官方匹配规则构造 `(背景, treatment, delta)` 监督对，建立可消融的双任务/残差模型：

```text
control/background head -> 预测背景蛋白质组
response head           -> 预测 FC 或残差 FC
final prediction        -> background prediction + response prediction
```

先比较“绝对值单任务”“FC 单任务后重建”“绝对值 + FC 双任务”三种最小实现，不要先引入复杂注意力结构。最终选择必须以第 3 节的分场景指标作证据。

### P0. 未见实体没有可外推的信息

`P0` 的 one-hot 对未见菌株和化合物没有语义，`P4` 的名称散列可提供稳定数值却不表达化学相似性。因此它们不能构成对 `S1`、`S2`，尤其 `S3` 的可信科学外推。

**风险：** 任何在随机划分或已见实体上看起来很好的模型，都可能在正式 OOD 场景崩溃。

**修复路径：**

- 封闭数据路线只使用官方字段，重点是更诚实的统计先验、条件/时间建模和响应分解；它应被视为强而透明的内部参照，而不是声称解决实体零样本。
- 开放知识路线为化合物构建经核验的 SMILES、分子描述符/指纹或公开预训练分子表征；为菌株构建来源明确的基因组、变异或序列表征。每一项资源都要记录版本、实体映射、许可证和获取时间。
- 从低复杂度的固定描述符 + MLP 开始，先验证表征能否提升对应 OOD 切分，再考虑可训练分子图网络或更大规模预训练表征。

### P1. 训练统计先验存在乐观偏差风险

`P1` 用完整训练部分计算菌株均值和化合物 delta 先验，忠实复现了文档基线，但同一行的目标参与了自身特征的聚合。

**风险：** 训练损失与训练内特征贡献被高估，模型选择可能偏向统计记忆。

**修复：** 对训练行使用 out-of-fold 或 leave-one-group-out 统计先验；对验证和提交行仍只查询相应实验训练部分得到的聚合量。该版本要作为新的对照实验，与原始 `P1` 分开命名，不能悄悄替换基线。

### P1. 测量上下文尚未以正确方式进入预测模型

官方任务明确把数据来源、仪器、板号等视为可用测量上下文，同时警惕把它们误学为生物机制。当前条件 MLP 为了忠实的最小基线而未使用这些字段。

**风险：** 忽略可预测的观测偏移会损失绝对保真度；直接与生物条件混接又会放大批次混杂并损害外推。

**修复：** 在响应模型稳定后增加受正则约束的观测校准分支，例如对来源/仪器/板号学习加性偏移或低秩偏移。生物分支与校准分支分开报告；未知上下文回退到零偏移，并对“有/无校准分支”做场景消融。

### P1. 高维输出结构、缺失机制和不确定性尚未被利用

4,422 个输出蛋白之间存在共变和通路结构，当前模型独立地输出全部维度。观测缺失也可能与丰度和仪器灵敏度有关，不能简单假设为完全随机。

**风险：** 高维参数估计不稳，高效应蛋白与低频响应被均方误差淹没。

**修复顺序：** 先使用仅由训练数据学习的低秩输出表示或蛋白协方差正则，再考虑开放知识路线中的 GO/通路/PPI 先验。高效应蛋白加权或 FC 相关损失必须在匹配与评分实现经过测试后再引入，避免错误的监督方向。

## 5. 分阶段研发路线

### 阶段 A：冻结问题与建立可信评估器

**目标：** 让每一次实验都回答“官方指标是否更好、在哪个泛化场景更好”。

**实施：**

1. 固化训练/验证分割、蛋白筛选、时间单位转换、匹配对照键和输出列顺序。
2. 实现六模块本地评分和可评分覆盖率报告；将无法匹配的样本、无共同观测的蛋白和退化相关情况显式记录。
3. 为 `B0`、`B1`、`P0` 至 `P4` 补跑同一套报告，得到真正的性能基线面板。
4. 增加按菌株、化合物、培养基、温度、时间和测量上下文切片的误差表。

**通过标准：** 相同输入运行可复现；每个指标可回溯到样本集合与训练冻结统计；任意模型不会只以一个总分掩盖 `S3` 失败。

**停止条件：** 如果官方评分细节更新，本阶段先更新评估器和测试，再开始模型比较。

### 阶段 B：响应目标与无泄漏统计先验

**目标：** 验证显式建模 FC 是否比绝对丰度回归更接近赛事目标。

**单变量实验顺序：**

1. 用 OOF 先验替换训练行的完整聚合先验。
2. 构建背景/响应的训练配对数据，并审计可用配对覆盖率。
3. 比较绝对值单任务、FC 单任务重建、绝对值与 FC 的双任务模型。
4. 仅在第 3 步显示正向信号时，探索上下文残差和药物残差的显式预测头。

**主要观察：** `S1` 的上下文残差、`S2` 的药物均值残差、所有 OOD 的原始 FC，以及高效应蛋白的方向准确率。

**通过标准：** 在不显著损害绝对保真度的前提下，至少在一个对应残差指标和原始 FC 上稳定超过相同输入的绝对值模型；多随机种子和场景切片方向一致。

**回退策略：** 若 FC 训练降低所有场景的绝对保真度且不改善 FC 指标，保留绝对值分支，仅将配对数据用于诊断，先检查匹配键、目标构造和损失尺度。

### 阶段 C：封闭数据榜的稳健模型

**目标：** 在不使用外部知识的约束下，做到强、可解释、可复现的竞争参照。

**候选改动：** OOF 先验、时间的连续/分段表示、稀疏条件交互、受约束的观测校准分支、训练学习的低秩输出结构。

**验证原则：** 每次只增加一个特征组或一个训练目标；`S1`、`S2`、`S3`、时间外推和六模块都要与阶段 B 最优模型比较。封闭数据路线的成功定义是提升稳健性和评分对齐，不是把无语义类别编码包装成零样本学习。

### 阶段 D：开放知识榜的实体迁移

**目标：** 提供未见化合物与未见菌株可利用的相似性信息，重点攻克 `S1`、`S2` 和 `S3`。

**工作流：**

1. 建立实体解析表：名称、标准化名称、外部标识符、来源链接、版本、许可证与置信等级。
2. 先做化合物固定描述符实验，观察对 `S1` 及 `S3` 的边际贡献。
3. 再做菌株序列/变异表征实验，观察对 `S2` 及 `S3` 的边际贡献。
4. 仅在两者各自有效时，加入菌株-化合物交互头并专门优化 `S3`。
5. 对每个外部表征做置零或置换消融，确认提升来自表征信息而非新增参数或数据切分偶然性。

**通过标准：** 对应未知实体场景存在稳定提升，且在置换表征后消失；所有资源、映射和许可可复现、可披露。

**回退策略：** 任何实体映射不确定、授权不清或收益只出现于已见实体时，停止进入主模型，保留为探索分支。

### 阶段 E：输出结构、校准与稳健提交

**目标：** 在已有有效实体信号的前提下提高样本效率、校准和高效应蛋白质量。

**候选改动：** 低秩解码器、蛋白相关性正则、功能通路先验、响应导向的多目标损失、种子稳定性和谨慎集成。

**门槛：** 任何复杂模块必须先超过阶段 D 的单模型，并在所有重点场景中不发生灾难性退化。只有误差互补且在固定验证协议下稳定的模型，才允许参与最终平均；不能用集成掩盖单模型缺陷。

## 6. 实验与交付规范

每个实验应产出一份简短但完整的记录：

| 字段 | 必须回答的问题 |
|---|---|
| 假设 | 这个改动为何可能改善哪个官方模块？ |
| 唯一变化 | 相比父实验改变了什么，未改变什么？ |
| 数据边界 | 使用哪些训练行、冻结了哪些统计量、是否使用外部资源？ |
| 结果 | 六模块、四类 OOD 场景、种子均值与波动如何？ |
| 消融 | 移除新模块、置零或置换后是否回退？ |
| 决策 | 进入主线、保留探索或回退，理由是什么？ |

代码与材料还需满足以下底线：

- 配置、随机种子、依赖版本、输入哈希、特征契约和模型清单随运行保存。
- 封闭数据榜与开放知识榜配置、代码路径、实验结果和文档明确隔离。
- 外部数据、工具、预训练模型和商业服务必须记录用途、版本、许可证、成本/权限和替代方案。
- 结果叙述必须把“本地验证证据”“生物学假设”“待验证机制”分开；不能把相关性或单一指标包装成因果机制。

## 7. 面向评审的叙事战略

技术性能只是总评的 45%。剩余部分要求方案能说明为什么这个问题值得做、为什么设计能解决特定瓶颈，以及别人如何复现或接续。

建议围绕一条可检验的主线组织材料：

> 面向未见菌株和未见化合物的酵母扰动响应预测，我们先以严格的匹配对照和残差评估将背景丰度、观测偏移与扰动效应分离；再以可审计的分子与遗传表征支持实体外推；最后通过高效应蛋白和响应方向验证预测是否具有实验筛选价值。

这条叙事需要由下列证据支撑，而不是由模型名称支撑：

- 与均值、匹配对照和最小条件模型相比的分模块提升；
- 对未见化合物、未见菌株和双重未知分别成立的消融结果；
- 可解释的高效应蛋白、通路或药物响应案例，并清楚标注其为预测假设还是外部证据支持的结论；
- 失败场景与边界条件，例如哪些化合物、菌株或时间段仍然无法可靠预测；
- 一键运行的代码、清楚的数据边界和可核查的资源披露。

隐藏机理分析适合用于赛后解释或展示，不应替代主榜上的定量验证。真正有说服力的科学价值来自“预测在严格 OOD 和响应指标上成立”之后，再提出可由湿实验检验的机制假设。
